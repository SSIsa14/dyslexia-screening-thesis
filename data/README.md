# Data provenance and publication notes

## Source

The original desktop and tablet datasets were obtained from the public data release associated with:

L. Rello, R. Baeza-Yates, A. Ali, J. P. Bigham, and M. Serra, "Predicting Risk of Dyslexia With an Online Gamified Test," *PLOS ONE*, vol. 15, no. 12, e0241687, 2020. DOI: https://doi.org/10.1371/journal.pone.0241687

The publication's data-availability statement links to the archived datasets through DOI: https://doi.org/10.34740/kaggle/dsv/1617514

## Files

### `raw/`

- `dyt_desktop.csv`: original desktop data, semicolon-delimited.
- `dyt_tablet.csv`: original tablet data, semicolon-delimited.
- `dataset_combined_original.xlsx`: desktop and tablet records consolidated before descriptive renaming.

### `processed/`

- `dataset_desktop_improved.xlsx`: manually improved desktop workbook.
- `dataset_tablet_improved.xlsx`: manually improved tablet workbook.
- `dataset_combined_improved.xlsx`: final combined workbook used by Orange and Python.
- `analysis_input.csv`: generated by `src/export_analysis_input.py`; intentionally not committed because it duplicates the final workbook.

### `dictionary/`

- `variables.xlsx`: working variable-description workbook used during manual renaming and documentation.

## Important distinction

The improved workbooks were created manually during the thesis. There was no original transformation script. The repository therefore documents the operations honestly rather than presenting a newly written script as historical evidence. See `docs/DATA_PREPARATION.md`.

## Before making the repository public

The source publication states that the datasets are publicly archived, but the repository owner should still confirm the dataset host's redistribution terms. If redistribution is not explicitly permitted, remove the copied raw and processed data from the public repository and retain this README plus download/preparation instructions.

The datasets are de-identified but concern minors and clinically established labels. Do not add participant identifiers or attempt re-identification.
